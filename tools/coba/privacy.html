Privacy Policy for coba

Last Updated: December 12, 2025

TL;DR: We only capture captcha images, send them to our server for solving, and don't store anything permanently. No personal data is collected.

1. Information We Collect

The coba extension collects the following data:

  • Captcha Images: Only the captcha images displayed on e-Courts websites are captured and sent to our server for processing.
  • IP Addresses: Your IP address may be temporarily logged in our server logs for operational and security purposes (e.g., preventing abuse). These logs are automatically deleted after 7 days.
  • No Personal Data: We do not collect, access, or store any personal information, browsing history, cookies, or login credentials.

2. How We Use Your Data

The data is used solely for the following purposes:

  • Captcha Images: Sent to our cloud-based API (hosted on AWS Lambda) to solve the captcha using machine learning.
  • IP Addresses: Used only for monitoring server health, preventing abuse, and troubleshooting errors. Not used for tracking or analytics.
  • The solved text is returned to your browser and automatically filled into the captcha input field.

3. Data Storage and Retention

  • No Permanent Storage: Captcha images are processed in real-time and are not stored on our servers or any database.
  • Server Logs: IP addresses and request metadata may be temporarily logged in AWS CloudWatch for up to 7 days for operational purposes, then automatically deleted.
  • Temporary Processing: Images exist only in memory during API processing and are immediately discarded after the response is sent.

4. Data Sharing

Your data is shared with the following parties:

  • AWS Lambda: Captcha images are sent to our server hosted on Amazon Web Services (AWS) Lambda for processing. AWS may temporarily process the data as part of their infrastructure but does not store or access it beyond standard logging.
  • No Third Parties: We do not sell, rent, or share your data with any third-party services, advertisers, or analytics providers.

5. Security

We take security seriously:

  • All data transmission between the extension and our server uses HTTPS encryption.
  • Our server is configured to reject unauthorized requests.
  • No data is persisted beyond the processing lifecycle, except for temporary server logs (automatically deleted after 7 days).

6. Permissions

The extension requests the following Chrome permissions:

  • Host Permissions: Access to *.ecourts.gov.in, *.dcourts.gov.in, and *.keralacourts.in to detect and solve captchas on these sites only.
  • No Broad Permissions: The extension does not request access to all websites or browsing data.

7. User Rights

You have the following rights:

  • Opt-Out: You can disable or uninstall the extension at any time from chrome://extensions/.
  • Data Deletion: Since we don't store permanent data, there is nothing to delete. Server logs are automatically purged after 7 days.

8. Children's Privacy

This extension is not intended for use by children under the age of 13. We do not knowingly collect data from children.

9. Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated "Last Updated" date.
