# blog.dattam.in — Blog

Dattam Labs blog. Built with Next.js 16 App Router.

**Live:** https://blog.dattam.in

## Commands

```bash
# From repo root
pnpm --filter @dattam/blog dev      # Dev server → http://localhost:3001
pnpm --filter @dattam/blog build    # Production build
pnpm --filter @dattam/blog lint     # Lint
pnpm --filter @dattam/blog check-types  # Type check
```

## Stack

- **Next.js 16** — App Router, Turbopack in dev
- **React 19**
- **Tailwind CSS v4**
- **@dattam/ui** — shared UI components from workspace
