# dattam-v1 — Archived (Legacy)

Original Dattam Labs website. Built with Astro 5 + Tailwind CSS. Deployed to GitHub Pages.

**This app is archived.** It has been superseded by `apps/dattam.in` (Next.js). Its git history was merged into this monorepo for reference.

## Stack

- **Astro 5** — static site generator
- **Tailwind CSS v3**
- **Deployment:** GitHub Pages (via `archive/astro-v1` branch)

## Commands

```bash
cd apps/dattam-v1
npm install
npm run dev      # http://localhost:4321
npm run build    # Output to dist/
```

## Notes

- Do not deploy or make active changes to this app
- Source of truth for old brand assets: `public/logo.png`, `public/favicon.ico`
- These assets have been copied to `apps/dattam.in/public/`
